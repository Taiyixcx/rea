# New-host deployment administration

This directory contains generic software deployment material, not target-analysis material.

- Start with README.md. This conversation is for deployment administration; never continue it as a formal experimental analysis conversation.
- Install/build/configure only the pinned software. Do not load a real experimental target, search for its answers, open old IDBs, inspect development traces, or retrieve prior analysis conversations during deployment.
- The private preparation repository, its Git history, host-specific manifests and acceptance archives are administrator-only. They are neither dependencies nor inputs for a formal agent.
- A successful configuration check is not a new-host qualification. Run the generic fixture and record actual receipts before claiming validation.
- Proposed client settings must preserve unrelated servers and credentials. Back up the affected file; apply only the role the user authorizes. Do not make native IDA tools visible to an REA-only formal agent.
- File/tool/context isolation must be tested with actual permissions; a different directory or these instructions alone is not an access boundary.
